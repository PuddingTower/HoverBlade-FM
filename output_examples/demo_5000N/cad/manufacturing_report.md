## How to use these files

- `blade.step` - open in FreeCAD / Fusion / any OCCT reader; it is a single solid manifold.
- `blade.stl` - watertight triangulation; slices and 5-axis toolpaths can be derived directly.
- `master_sections.dxf` - one closed template polyline per station plus a magnified trailing-edge detail (region x/c > 0.9) on layer `TE_MARKERS`; the `DATUM_25C` line is the 25% chord rotation reference used by the coordinate files.
- Section coordinates are also available as CSV in `../sections/` with normalised and physical columns.

## Statement on the trailing-edge constraint

A sharp trailing edge is impossible in this package by construction: the geometry generator projects every station onto the specified minimum thickness before any file is written, and this report re-measures the produced coordinates rather than trusting the request.
